Install

Prebuilt release

curl -fsSL https://raw.githubusercontent.com/chiuta/PolyTabletop/main/install.sh | bash

From source

git clone https://github.com/chiuta/PolyTabletop
cd PolyTabletop
cargo build --release
./target/release/polytabletop list

Docker

docker build -t polytabletop .
docker run --rm -it polytabletop play chess

First game

polytabletop list
polytabletop play chess
polytabletop --lang fr play go --level hard
polytabletop host chess        # polytabletop join 192.168.1.20:7878
