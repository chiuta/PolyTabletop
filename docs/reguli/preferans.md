# Preferans (2 jucători) (`preferans`)

Joc rusesc de levate cu 32 de cărți, adaptat pentru doi: 10 cărți fiecare și un talon de 2. Licitezi numărul de levate și atuul (`licit 6h`, `licit 7nt`; ordinea s < c < d < h < fără atu). Declarantul ia talonul (`talon`), aruncă 2 cărți (`pune 7h 8c`) și joacă; trebuie să răspunzi la culoare, iar fără culoare tai cu atu. Reușit = +2·(nivel−5), ratat = minus pe fiecare levată lipsă. 6 mâini; mâna adversarului este ascunsă.

## Scop

Vezi regulile de mai sus; câștigă jucătorul care îndeplinește condiția de final a jocului.
