# Călătoria Oracolului (daruri, drumuri și conversii) (`calatoria_oracolului`)

Categorie: Strategie. Doi jucători (Jucătorul 1 contra Jucătorului 2 sau calculatorului). Pornire: `polytabletop play calatoria_oracolului --seed 1`. Sursa implementării: `polytabletop-games/src/calatoria_oracolului.rs`.

Joc original, variantă proprie inspirată doar de mecanica generală a genului (clean-room); nu folosește nume, texte, hărți sau cărți ale unui produs comercial.

> Variantă originală: Șapte runde: câte trei muncitori pe locuri libere (câmp, pădure, carieră, templu…); conversii limitate și bonus de set (+2 pentru fiecare set complet). Mutări: pon s, cumpar j, conv i, pas, ronda.
