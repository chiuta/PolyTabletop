# Ô ăn quan (Vietnam) (`o_an_quan`)

Inel de 12 gropi: 5 mici pe latură (5 pietre) și două quan cu mandarin (10 puncte). Alegi o groapă proprie și sensul (3+ = orar, 3- = antiorar), semeni pietrele; următoarea plină se ia și se continuă; după o groapă goală, groapa plină următoare se capturează. Rândul gol: pune5. Câștigă cine adună mai multe puncte.

## Scop

Vezi regulile de mai sus; câștigă jucătorul care îndeplinește condiția de final a jocului.
