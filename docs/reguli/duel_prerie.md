# Duel în Prerie (`duel_prerie`)

Categorie: Zaruri. Doi jucători (Jucătorul 1 contra Jucătorului 2 sau calculatorului). Pornire: `polytabletop play duel_prerie --seed 1`. Sursa implementării: `polytabletop-games/src/duel_prerie.rs`.

Joc original, variantă proprie inspirată doar de mecanica generală a genului (clean-room); nu folosește nume, texte, hărți sau cărți ale unui produs comercial. Titlul în opt limbi se află în `polytabletop-games/data/i18n/titles_C5.tsv`.

> Variantă originală: cinci zaruri (săgeată, dinamită, foc aproape, foc departe, bere, mitralieră), trei aruncări (arunc, reia m, gata). Săgețile se iau din teanc și se blochează, dinamitele se blochează (trei = pierzi o viață și tura); când teancul se golește fiecare pierde atâtea vieți câte săgeți are. Tragi doar cu fața potrivită distanței (alternă). Cine ajunge la zero vieți pierde. Mutări: arunc, reia m, gata.
