# Tenis de masă (Ping-pong) (`pingpong`)

Un set la 11 (diferență 2). Cine lovește alege zona (st, ct, dr) și forța (sigur, atac, smash): ct-atac; apoi schimb rezolvă lovitura. Forța mare = mai multe mingi ratate, dar mai greu de returnat; adversarul pierde 25% pentru fiecare zonă dintre poziția lui și minge. Serviciul trece la 2 puncte.

## Scop

Vezi regulile de mai sus; câștigă jucătorul care îndeplinește condiția de final a jocului.
